# Third-party visual notices

## Phase 1 model sources

All five Phase 1 representative model families are released under Creative Commons CC0 1.0 by their identified creators on OpenGameArt.

Runtime files are project-produced GLB derivatives. The project preserves exact source-page, acquisition, archive-hash, runtime-hash, and conversion evidence in the resource ledgers.

No Phase 1 runtime asset is hotlinked. No account, payment, or click-through acceptance is required for the selected sources.


## Phase 2 living actors

Phase 2 candidate source archives are CC0-1.0 and are preserved separately from derived runtime GLBs. Exact acquisition URLs and SHA-256 values are recorded in the Phase 2 source/provenance evidence. Inclusion in the candidate ledger does not by itself mean a model has passed production visual acceptance.
